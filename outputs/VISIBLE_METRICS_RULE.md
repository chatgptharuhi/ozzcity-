# 数値表示の整理（2026-10-30）

## ユーザー合意
主画面にある指標だけを数値として見せる。確認回答により、経験と人間関係も残す。主指標は資金/収入/借金、信用/役目、健康、ストレス、危険度、経験、人間関係。費用・報酬・成功/失敗確率・期間・登録上限など、行動を判断するための数字は残す。

組織の不満、疑念、義理、幹部の支持、所内のつながり、家族の資金負担指数、喫煙習慣の内部値、街の治安/捜査の注目/対立の脅威といった危険度の入力値は、内部計算に残して数値だけを非表示にする。

## 表現
- 組織の不満−2 → 「組内の不満が和らぐ」
- 幹部の支持−1 → 「上役の後押しが弱まる」
- 義理＋25 → 「支援者の頼みを断りにくくなる」
- 所内のつながり＋3 → 「所内の仲間と打ち解ける」
- 疑念＋8 → 「周囲に疑われやすくなる」
- 捜査の注目/対立の脅威の生値は隠し、選択肢の既存の摘発/襲撃リスク変化は残す。
- 昇進に必要な後押しは「確保できている/まだ足りない」と伝える。数字の閾値や加点の内訳は並べない。

数値を消すだけで、隠れた効果しかない選択肢を「変化なし」としない。変化がある場合は短い説明を残す。上下限で内部値が変わらない場合は、変化があるように付記しない。

## 実装範囲
共通効果表は許可リストで数値を制御。説明文・メタ情報・昇進/刑務所/移籍・支出・人生記録にも同じ表示変換を使う。過去の記録は描画時に変換し、保存済みの履歴や数値は書き換えない。DOMの後処理はテキストだけを更新し、購入等のボタンやハンドラーを作り直さない。

組織の不満の既存用途：昇進審査の減点、内紛/移籍等の出現、月次の衝突、出所支援の成立率等。今回は値や係数を調整しない。給与の未払い率は別の組織設定で、これを不満度へ一本化する変更もしていない。

## 検証と残件
独立VMで通常選択肢1461描画（複数状態）、刑務所・昇進・メタ情報・過去記録を確認。費用/確率/期間/主指標数値が残ること、内部効果/プレビュー前後の状態が不変なこと、テキスト更新でクリック処理を壊さないことを確認。実ブラウザーの画面操作は未実施。実セーブと進行中のブラウザーは操作しない。
