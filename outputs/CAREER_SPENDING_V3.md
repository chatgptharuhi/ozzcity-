# 信用と役目・支出の初回追加（2026-10-29）

## 昇進
- 従来は推薦が出る約8%の抽選に加えて合否抽選、失敗後18か月停止。高信用でも見習いに留まった。
- 見習い卒業：実働12か月・職務合計12か月・経験4・信用20・処分なし。条件を満たせば通常相談で認定。合否抽選なし。信用＋3。過剰な見習い実働は次段階へ最大12か月持ち越す。
- 次段階：その役目24か月・合計36か月・経験10・信用50。幹部段階：その役目36か月・合計84か月・経験20・信用80・幹部支持1。
- 条件成立後は通常相談で審査を提示。上位は抽選、成立上限75%／幹部55%。年齢・実働・信用・経験・支持・不満等を反映。成功信用＋5、失敗信用−6・ストレス＋6・支持があれば−1、再審査6か月。辞退後も6か月空ける。
- ボス条件・空席と後継争いは維持。軽い担当・休業中は審査を差し込まない。実際の権限上昇で危険も増える。

## 支出（元はMXN、画面は従来固定換算のUSD）
| 項目 | 設定 | 根拠と限界 |
|---|---|---|
| 自分の部屋 | 初期5,000、家賃4,000/月 | CONASAMI 2024資料の適切な住宅の家賃推計3,767/月を丸める。地域差・2026物価を厳密に再現する値ではない |
| 敷金・引越し | 4,000返還可能＋1,000費用 | ゲーム上の仮定 |
| 私用中古車 | 150,000一括 | VW認定中古車公式在庫の149,999〜という販売例。全国平均ではない |
| 車維持 | 使用1,500/月、休止・収監500/月 | ENIGH2024の車両燃料3,068/四半期（全世帯平均）を参考に燃料1,000＋保管・整備等500を仮定。所有者限定の実測費・保険見積ではない |
| ごちそう | 600一回、人間関係＋2、3か月間隔 | ENIGH外食3,896/四半期を参考に設定。会食一回の統計ではない |

家賃は既存生活費の40%を住居相当と仮定し置換、残り60%と同居加算は維持。二重に家賃を加算しない。借りた月からストレス−2/月。敷金返還は解約時。車の維持は購入翌月から、使用時ストレス−1/月。売却目安は購入額を月0.5%減価、最低20%、売却15%控除（すべて調整値）。現金と車の売却目安・敷金を別表示。車は仕事用の装備ではなく私物。

収監中も家賃と車の保管費は残る。家賃不足は既存の生活費未払へ、車は維持費不足なら使用停止し新規借入なし。車の費用を払えない月は保管費も徴収せず、厳密な滞納・差押えモデルは未導入。翌月収支に家賃・車を反映。通常給与・休業・護衛・送金の既存処理は維持。

## 有料リスク対策：提案段階
消費支出と異なり、架空の犯罪組織の対策価格と効果を推計できる統計はない。以下は今後合意するゲーム設定案で、今回は未実装。
- 摘発：既存の高額休業をお金の管理に維持。追加するなら代役・業務縮小の継続費。収入や昇進実績を手放し、職務の露出だけを減らす。進行中の捜査・過去の事件・依頼圧力は消さない。
- 襲撃：護衛強化を月契約にする。通常襲撃の発生率の軽減と既存の被害軽減を区別。特別な報復や裏切りは対象外、無敵にはしない。
- 費用案は各US$500〜1,000/月。効果は該当するリスク部分の20〜30%減から検証し、総危険度を20〜30ポイント直接引かない。
