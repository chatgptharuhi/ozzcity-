# 危険UIの整理（2026-10-31）

正本の危険を1カードにまとめ、摘発/襲撃を月間見込みで別表示。原因と対策は対策欄へ。警告色は内部の既存指数を維持し、判定/資金/時間/保存形式は変更しない。

- 対策は費用→効果→操作。重要な給与/実働/期間/信用損失は常時表示、残りは詳細へ。
- 選択肢の危険効果は指数差から月間見込みへ。変化する摘発/襲撃だけ示す。丸めで同表示になる場合も「少し下がる/上がる」。
- 1%未満を0%とせず、99%超も100%保証としない。操作画面の小数％を整数/範囲表示へ。出典資料の引用数値は維持。
- 加入済み警護強化/代役も、その契約がない状態との比較で効果を示す。
- 構文とソース差分を確認。テスト/実画面確認は未実施。実セーブ/ブラウザー未操作。

残る課題：全選択肢の所持金不足による進行不能の棚卸し、住み替え/隠れ家の役割と金額の確定、組織と個人の防衛費分離、長期経済/危険バランスの実プレイ検証。低確率表示が同じになる対策の分かりやすさもプレイ評価が必要。
