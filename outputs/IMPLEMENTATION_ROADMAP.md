# 実装順とプロフィール・アイコンの方針

2026-10-31。共通ルールはGAME_DESIGN_RULES.md、選択肢はCHOICE_QUALITY_RULES.mdに従う。ユーザー承認の実装順。1件ずつ区切り、未確定の金額/効果を確定扱いしない。

1. 資金不足の選択不能をなくす。通常/動的/保存済みイベントまで対象。原則は無料の対応を残し、自動借入を増やさない。場面固有の不利益は根拠と一回/継続を明示。全候補が支払不能なら進行を塞がない最後の対応を用意。これは各候補の意味を見直す作業の代わりではない。
2. 住み替え・隠れ家。日常生活を整える住まいと危険期の一時退避を区別。取得/敷金/家賃/維持/売却と、滞在中の仕事・人間関係の代償を設計する。危険を全消去しない。価格と効果は未確定。
3. 防衛費。組織会計と個人の護衛費を区別。任意契約の効果/解禁/継続費を短く示す。
4. 長期経済・危険のバランス確認。ユーザーの実プレイと、許可を得た独立環境の検証を区別。実セーブを初期化しない。
5. プロフィール。現在の職業/実際の役目/過去の経歴/暮らし/家族関係/主な人生記録を中心にする。全国の参考統計や制作説明は人物情報から分ける。「累計収益」は現在資産でも純利益でもなく、給与/報酬/一部の賭け収支等が混ざる旧集計。収入・賭け収支・支出の範囲を決めてから再命名し、履歴がない過去分を推測して補完しない。
6. アイコン。添付参考のような小さなドット絵を候補とし、職業を基本に役目/立場の違いが分かる構成。職業と地位を混同せず、文字ラベルも残す。人物とカジノ各ゲームのアイコンを同じ画調で揃える。参考画像は雰囲気の参考で、そのまま転用しない。画像制作はこの段階で行う。

危険UI：入口/カードは一つ、摘発と襲撃の数値は別。影響する危険だけ各選択肢に示す。操作画面の％は整数/1％未満、内部計算は維持。小数の細かさを現実の予測精度とは説明しない。詳細COMPACT_RISK_UI.md。
